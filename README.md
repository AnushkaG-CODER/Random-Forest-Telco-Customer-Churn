
# Random Forest - Telco Customer Churn Prediction

## Project Overview
This project uses Machine Learning to predict whether a telecom customer is likely to leave the company (Churn) using the Random Forest Classification algorithm.

## Dataset
- Dataset: Telco Customer Churn
- Source: Kaggle
- Records: 7,043
- Features: 21

Dataset Link:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Steps Performed
1. Imported required libraries.
2. Loaded and explored the dataset.
3. Handled missing values.
4. Encoded categorical variables.
5. Split the dataset into training and testing sets.
6. Implemented Random Forest Classifier.
7. Evaluated model performance.
8. Visualized feature importance.
9. Performed hyperparameter tuning and cross-validation.

## Model Performance
- Accuracy: 78.92%
- Precision: 0.643
- Recall: 0.458
- F1 Score: 0.535

## Conclusion
The Random Forest model was used to predict customer churn. Hyperparameter tuning improved the model's performance. The project also identified important factors that influence customer churn.
